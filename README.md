# proyecto_FS3

🚀 Paso 1: Compilar el proyecto
En la terminal PowerShell, navega a la raíz del proyecto: primer-proyecto-fs01-main"
Luego compila:  
.\gradlew.bat clean build  
⏳ La primera vez tarda más (descarga dependencias). Las siguientes veces es más rápido.  

🎯 Paso 2: Ejecutar la aplicación  
.\gradlew.bat bootRun  
Verás una salida como esta cuando esté listo:  
 Tomcat started on port(s): 8080 (http)  
 Started PrimerProyectoApplication in X.XXX seconds  
✅ ¡Tu API está corriendo en http://localhost:8080
